# moldflux

Mold color flux values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/moldflux/

## Install / run

```bash
git clone https://github.com/theworker02/moldflux.git
cd moldflux
node src/cli.js
node --test
```
